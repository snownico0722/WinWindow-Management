WinWindow Management 1.0 初版。

## 版本亮点

- **智能桌面整理（Smart v3.3）** 支持手动整理和撤销，自动整理可选关闭、轻度或完整。两扇窗口来回使用时，会权衡保留各自的工作尺寸与实际可见内容，并为后续并读留出空间。
- **保护正在操作的内容**。在常见聊天和办公应用里读写时，优先保留当前视图的位置和已露出的内容。启用个人摆放习惯后，多次独立的手动调整可以影响后续整理。
- **Chrome 和 Edge 布局辅助**。直接运行即可利用页面身份、可见文字区域和编辑焦点。可选扩展还能区分同地址的不同标签页，并在获得站点授权后识别正文列和静音播放的视频。扩展文件随源码提供。[扩展安装说明](https://github.com/snownico0722/WinWindow-Management/blob/v1.0.0/docs/BROWSER_EXTENSION.md)
- **窗口管理工作台**。在同一行操作置顶、静音、透明度、鼠标穿透、收起与恢复和后台保持。支持拖拽置顶、悬浮胶囊、托盘和全局快捷键。

## Windows x64 下载

- **WinWindow-win-x64.exe** 需要 [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0)。
- **WinWindow-win-x64-self-contained.exe** 内置 .NET，下载后可直接运行。
