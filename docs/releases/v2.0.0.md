WinWindow Management 2.0 正式版。这个版本重点改进了受管窗口的操作和恢复，并修正了多屏整理与数据保存的问题。

## 窗口管理

- **受管窗口的顶栏工具条可横拖**，会随窗口移动，并按所在显示器的缩放调整。透明度快捷按钮只显示图标，再点一次恢复原值。
- **收起为图标后可拖到另一屏再恢复。** 直接点击仍优先回到原来的位置；如果原位置已不可达，则优先保留可从屏幕上找回窗口的入口。
- 改进了已记住的 WPF 窗口重启后的匹配。仅在能唯一识别新窗口时接管。

## 自动整理与可靠性

- 修复双窗并排时，拖动右窗左边框不联动的情况；修复 150% 等分数缩放下，部分贴边候选因像素取整被误拒的问题。
- 浏览器中继遇到单次可恢复的网络错误后会继续接收。
- 设置、窗口摆放习惯和布局反馈暂时无法读取时，不再用默认值或空记录覆盖原文件。

## Windows x64 下载

- **WinWindow-win-x64.exe**：需要 [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/10.0)。
- **WinWindow-win-x64-self-contained.exe**：已内置 .NET，可直接运行。
