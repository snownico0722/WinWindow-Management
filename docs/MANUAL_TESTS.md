# Windows 实机验收

自动检查使用真实 WinForms / WPF 目标及完整主程序；不是所有游戏或硬件的兼容认证。

| 场景 | 应验证的行为 |
|---|---|
| 全屏 / 无边框游戏 | 强制最小化显示真实状态；失败则隐藏；打开其他应用不因“显示桌面”解除而带回游戏。后台帧率和挂机单独记录。 |
| 0% + 穿透 + 收起 | 列表/托盘/恢复快捷键仍可找回。恢复窗口保持设置；恢复原样撤销修改。 |
| 同名窗口 | 多个路径/类/标题相同目标不随机匹配，已关闭 HWND 不复用到新进程。 |
| 权限 | 普通实例操作提权目标失败有真实反馈；普通第二次启动能唤醒管理员实例，不自动提权。 |
| 混合 DPI | 100%、150%、200% 跨屏拖动、最大化、收起/展开；尺寸和点击区域准确。 |
| 焦点与唤醒 | 切到普通窗口后退到其后；托盘、快捷键、第二次启动可唤回；焦点策略关闭时不残留临时 TOPMOST。 |
| 小窗手势 | 左上角名称点击收成 180×50 小窗，再点展开；拖动名称/小窗只移动。中间标题栏只拖动。恢复尺寸、最大化与手动置顶选择。 |
| 行内直接操作 | 图钉、穿透、滑块、数值输入、收起按钮不误触标题唤醒；标题单击不改变已经最大化的目标尺寸。 |
| 取消与移出 | 单行/全部取消置顶不删列表、不重置透明度；× 取消置顶并移出，不关闭目标，即使它原本置顶。 |
| 添加 | 选择器搜索/Enter/Esc/点外关闭；拖动到目标只置顶，重复拖动不取消；Esc 可取消拖动。 |
| 多行透明度 | 连续拖动不中断；正在输入的文字不被旧结果覆盖；切换行或滚动复用后不串目标；0% 不被夹值。 |
| 快捷键 | 冲突保留原绑定；设置支持交换组合；Delete 清空；Esc 恢复原值。 |
| 关闭与退出 | 按设置藏托盘或退出；退出不被单个目标卡住；未完成记录保留，下一次恢复。Explorer 重启后检查托盘。 |
| 界面 | 主列表是行内操作，没有右侧检查器；最小尺寸与深色模式按钮可见；右键菜单不丢项。 |

```powershell
dotnet build src/WinWindow/WinWindow.csproj -c Release
dotnet src/WinWindow/bin/Release/net10.0-windows/WinWindow.dll --self-test TestResults
dotnet run --project src/WinWindow/WinWindow.csproj -- --dev
```

开发模式独立状态目录和单实例锁，快捷键仍为系统资源。测试进程仅结束自己启动的子进程，不触碰用户现有的管理器实例。
