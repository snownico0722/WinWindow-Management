# Windows 实机验收

自动测试用独立测试进程验证 Win32 实际状态并输出 WPF 渲染截图；不是全屏游戏兼容认证。

| 场景 | 应验证的行为 |
|---|---|
| 全屏 / 无边框游戏 | 强制最小化后打开其他程序，游戏不会仅因“显示桌面”状态解除而重新出现；显示“已最小化”或真实的“已隐藏”，恢复后回到原窗口状态。游戏暂停/后台帧率单独记录。 |
| 0% 不透明度 | 窗口完全不可见后，列表仍有目标；托盘“找回窗口”和 Win+Ctrl+Shift+R 恢复可见性。 |
| 透明 + 穿透 + 收起组合 | 恢复窗口保留透明/穿透选择；恢复原始状态撤销全部本程序修改。 |
| 多个相同程序窗口 | 程序路径、类和标题相同时不随机应用规则；关闭并重新打开不同实例不会沿用旧 HWND。 |
| 原本置顶 / 透明的窗口 | 移出管理或退出后恢复原本设置，不强行改成普通不透明窗口。 |
| 权限边界 | 普通进程控制提权窗口失败时报告失败，不假成功、不自动提权；跨权限第二次启动能唤醒管理员实例；失败需有可诊断结果。 |
| 主程序唤醒 | 主程序非手动置顶时，从任务栏、托盘、快捷键、第二次启动都可尝试唤出；失焦后取消焦点临时置顶，不留下唤醒临时状态。 |
| 小窗 | 进入/退出保持原工作台尺寸、最大化状态和长期手动置顶选择；标题栏中间拖动不触发小窗。 |
| 窗口尺寸 / DPI | 100%、150%、200% 两屏之间移动、缩放、最大化；主窗口可放大且不遮挡任务栏，设置与按钮没有截断。 |
| 快捷键冲突 | 申请被占用的快捷键失败时保留原快捷键；新设置中的交换组合可用。 |
| 托盘 / 关闭 | 默认关闭藏托盘；取消设置后关闭真正退出并恢复目标；Explorer 重启后检查托盘恢复。 |
| 强制结束管理器 | 隐藏/0% 窗口后结束 WinWindow，再次启动能恢复仍存活的目标；不会操作已被复用的句柄。 |
| 普通退出 | 尽力恢复目标，900ms 上限后退出；失败记录保留，不能拒绝退出或假报成功。用户规则保留。 |
| 失焦与唤醒 | 非手动置顶时切到普通窗口后应退到其后面；关闭焦点策略后主动唤醒不能残留 TOPMOST。 |
| 连续调整不透明度 | 持续拖动不中断；输入过程中旧结果不覆盖未提交文字；切换选择后仍应用到原目标。 |
| 精简界面 | 两栏直接操作；设置可一步返回；880×560 下主要按钮可见，不出现被删侧栏/宣传语/计数/技术元数据。 |

## 本地构建与测试

```powershell
dotnet build src/WinWindow/WinWindow.csproj -c Release
dotnet src/WinWindow/bin/Release/net10.0-windows/WinWindow.dll --self-test TestResults
dotnet run --project src/WinWindow/WinWindow.csproj -- --dev
```

`--dev` 使用独立数据目录和单实例锁，不读写正式配置。快捷键仍属于系统级资源，和正式程序冲突时在开发实例里改为其他组合。
