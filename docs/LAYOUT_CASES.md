# 布局经验

记录影响多个场景的反例。保留用户意图、观察、因果证据和复验条件。每次修订写明适用版本；快照编号是现场索引。模型当前取舍见 [设计决策](DECISIONS.md)。

## 四、五版 · 黑边属于哪一扇窗

用户看视频时也在使用同屏的另一扇窗。第四版的上下黑边可通过只改浏览器高度消除。第五版的侧边黑边则需要评估宽度。观看区域从整个外框改用实际视频视口后，能分别计算画面收益和邻窗遮挡。全局候选中应包括“只调目标轴”，几何精修同样要保留其他窗口的有效视野。

复验时同时检查主窗和后台窗的坐标、有效画面、可见区域以及候选的实际提交。对照场景中，若扩大视频确能利用空白且保住邻窗视野，应允许它扩大。单个请求的正确输出不能外推成游戏应用一律固定。

## 第六版 · 用户已经把前景窗移回一侧

**现场。** 工作区 2560×1380。浏览器从左侧被移到 x=582，用户把它拖回 x=69，松手辅助贴到 x=0。约 6.7 秒后同一窗口又被移至 x=582。前后游戏的总可见比例相同，采样中最大可见块的宽度从 1063 px 减至 582 px。

**能查实的机制。** v1.3 的调度器会因持续指针交互再次请求工作区整理。四秒手势记录此时已过期，默认居中只检查可管理的邻窗。旧快照未保存具体入队原因，无法还原当时哪一个鼠标按键或并发通知发起请求。

**复验。** Smart v1.5 继续记点击与滚动；只有注意力变化时，整理队列保持空闲。把旧请求强行送入新求解器，仍应保留侧面的浏览器和后台的连续视野。左右镜像、全屏或最大化的陌生参考窗适用相同判据。v1.5 在参考消失后重新允许独窗默认居中。v1.7 修正了这一点。用户只回拖横向位置时应只修正水平推断，即使他未精确回到原坐标。邻窗集合或几何改变后，根据新情境重新判断。

## 第七版 · 消掉的黑边在下一次开窗时回来

Smart v1.5 的记录里，同一播放窗先从 1400 × 908 收到 1400 × 840，随后 Edge 进入前台，普通配对又给了它 973 像素高度。第二次收去上下黑边后，切到 Chrome 与 Typora 配对又把外框改窄、拉高。资源管理器进入前台时，两次决策只隔 117 毫秒，刚收掉的宽度又被加回。快照能确认每次外框和被测视口，无法复原视频的每一帧。

复验时从每一次已提交的去边结果开始，重放后继开窗和焦点切换，分别检查视口比例、邻窗可见性和留出的操作空间。对照场景要允许在较窄分栏内等比缩放、允许继续调整搭档，并在标签变化、出现不同的可靠测量或用户亲手改变尺寸时撤回旧依据。

## 单侧独窗与腾出来的空间

同一份原位可读的窗口，分别模拟焦点切换、关闭另一栏及显式整理。自动切换和关闭邻窗不会给横移新增收益。对照场景中，一个过窄的贴边窗口仍可向空白侧长宽；有真实遮挡时也应继续寻找可读位置。镜像左右列、负坐标显示器以及退到后台的最大化参考窗，用来检查结果是否依赖某一个固定坐标。

同一对应用的人工方位还需在“共同使用”和“只有一扇参与当前工作”两种条件下回放。将方位样本直接编译为无条件配对，可能给无关窗口也增加动作。分别比较有无个人规则的移动对象、手动补调误差和反例。

## 局部资料卡、独立通话与后台监看

在聊天主窗中点击联系人资料，分别验证先显示再获取焦点、弹层未激活、关闭返回宿主、带原生 owner 的浮层。局部交互的整个过程中不能单独产生自动整理请求，鼠标拖动卡片也不能教会模型主聊天窗要靠哪一侧。对照同应用的独立文章、通话窗和用户主动把小窗扩大为独立工作区的操作。两个进程和窗口类完全相同的窗口仍可能承担不同任务。检查快照或长期记录的 surfaces 文件，按宿主、子窗、时间和判定理由归因。用户未指出的标题语义应保留未知。

在 16:9 工作区留一扇可见的后台参照面，用前台浏览器覆盖一部分，叠加第三扇窗。比较旧布局真正露出的像素在新布局里还剩多少，另外核对前台正文宽度和手工补调次数。对照情形是只缩短带上下黑边的视频窗，或用户主动将游戏改成大窗。保持后台窗的 X、Y 坐标不能单独作为通过标准。多个遮挡窗重合的区域只算一次。

## 同侧开窗，另一栏已有正文

**观察。** 左边有一扇可见的工作窗，右边打开新窗覆盖刚用过的窗。一次自动开窗整理把新窗横移到左侧。用户拖回右侧后，在右侧前后台间切换或再次松手，系统先后把主窗和搭档移到左边。原记录里可分别查到系统目标、实际落点、用户拖动起终点和下一次请求。

**判据。** 用陌生应用、负坐标工作区和左右镜像复验。可读叠放允许留下；一个未参与当前配对的对侧工作窗仍应保有可见正文。手动回拖之后，开关邻窗、仅改变层级、同侧贴边均不能把这次方向选择清空。下一次反向拖动应立即改变方向。独立应用每次创建新 HWND，并不足以推出必须平铺的意图。

**对照。** 拿掉对侧窗，或让它完全不可见，使用同一组双窗恢复独立开窗分栏的机会。若前景还不能阅读，仍可改善尺寸。人工要求整桌平铺继续由显式命令处理。旧记录缺少逐窗的手动侧别时，用原状回放核对几何，用事件序列回归核对新信号的产生和失效。
