# 浏览器布局辅助

Chrome 和 Edge 的当前网页可向 WinWindow 提供布局信号。直接运行 WinWindow 即可使用无障碍读取。安装可选扩展后，浏览器还能直接报告标签页、声音和网页内部的位置。

| 信号 | 直接运行 WinWindow | 装上扩展 |
| --- | --- | --- |
| 页面身份 | 从无障碍文档读取 URL。成功识别换页时清掉旧的去黑边缓存。 | 补充活动标签和文档的身份。同一个 URL 在两个标签打开时也可区分。 |
| 阅读与编辑 | 估算可见文字区域，识别有焦点的可编辑控件。 | 授权站点后，读取顶层页面的正文列边界和编辑焦点。 |
| 媒体 | 使用已有的音频、画面变化和像素取样。 | 读取活动标签的声音状态。授权站点后可识别静音但在播放的主视频，为其播放器保留可见范围。播放器足够大时，去黑边在其区域内取样。 |

手动整理立即使用已有样本。扩展只在运行中的桌面端确认浏览器发生变化，或最近有整理请求时测量页面。WinWindow 退出后，扩展仅询问连接状态。

这些信号在已有整理请求中参与判断。点链接、换标签、播放视频或授权网站本身都不会触发桌面整理。「关闭、轻度、完整」的授权照常生效。探测暂时不可用时，现有标题和视觉逻辑会继续工作。

## 安装扩展

1. 准备包含本功能的 WinWindow Windows 可执行文件，以及仓库的 `browser-extension` 目录和 `scripts/browser-extension.ps1`。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发人员模式，使用「加载已解压的扩展程序」选择 `browser-extension`。复制扩展详情里的 ID。
3. 在普通权限的 PowerShell 中运行以下命令，使用实际文件路径和扩展 ID。如果两款浏览器的 ID 不同，用逗号把它们一并传给 `-ExtensionId`。

   ```powershell
   .\scripts\browser-extension.ps1 -WinWindowExe 'C:\Apps\WinWindow-win-x64.exe' -ExtensionId '实际的扩展ID'
   ```

4. 重启 WinWindow 的常规实例，在扩展管理页重新加载扩展。标签页辅助随后可用。打开需要更深适配的网站，点工具栏里的扩展图标并允许访问该站点。图标上的 `ON` 表示此站已授权，再点一次可撤销。

移动可执行文件后重新执行第 3 步。卸载扩展时可运行 `./scripts/browser-extension.ps1 -Remove` 移除本机连接。扩展通过 Chromium 的 [Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging) 发消息给 WinWindow，适用于常规数据目录。当前以 Chrome / Edge 为目标，扩展以解压目录交付。

## 实现边界

- 页面身份的散列、标签标识与当前状态只用于本次运行。扩展发送区域和状态，不发送正文、输入值、页面标题或原始 URL。WinWindow 的原有诊断仍可记录窗口标题，以及求解实际使用的区域和布尔信号。扩展会跳过无痕窗口。
- 扩展按可见窗口的活动标签取样。页面内部信号首版读取顶层文档，嵌入框架和浏览器内部页面可以继续使用桌面的通用逻辑。已加载、可访问的文档才能提供免扩展信息。
- 多个窗口都可能对应同一份浏览器报告、混合 DPI 无法核对外框、或报告已过期时，WinWindow 会舍弃这份报告。浏览器缩放后的播放器位置需要与原生内容视口匹配才会被采用。黑边仍由像素采样确认。

## Windows 验收

1. 分别用 Chrome 和 Edge 打开两份标题相同、URL 不同的页面，并在同一拿到视频比例的窗口内切换。原页面的去黑边缓存应失效。打开另一扇同标题浏览器窗口，再检查两窗不会互用证据。
2. 打开有正文和编辑框的页面，自动整理打开时对正文滚动、在输入框打字、再切标签。分别确认操作不会独立发起整理，以及后一轮真正的桌面整理能保护已识别的编辑视图。
3. 加载扩展，先不授权站点检查标签辅助。随后在授权站点播放静音视频，把浏览器留作旁边已露出的参照窗。观察真实整理是否保护该播放器。暂停或撤销授权，对照新的整理请求是否退回现有证据。
4. 用同尺寸同标题的两个浏览器窗口、不同显示器和 125% 或 150% DPI 测试身份关联。移到另一块屏幕后重新触发正常整理。匹配证据有歧义时应保持通用行为。
