# 产品与实现决定

## 2026-11-10 · 独立 WPF 重写

用户决定：用 C# / WPF / .NET 10 在 WinWindow-Management 实现独立的 Windows 窗口管理系统，使用 PaperTodo 暖纸视觉，取消透明度下限，加入强制最小化，主界面不能局促。

- 默认 1180×760 DIP，最小 880×560，可最大化，无最大尺寸限制。小窗只作可选入口，返回时保留原尺寸、最大化和长期置顶选择。
- 不透明度 0–100%。完全透明或隐藏后仍可由列表、托盘和恢复快捷键找回。
- 强制最小化只执行一轮：保存 WINDOWPLACEMENT → 异步请求 → 验证真实 IsIconic → 异步位置恢复尝试 → 隐藏兜底。不是持续压后台，不注入游戏。
- “恢复窗口”保留管理设置，“恢复原样”撤销本程序修改。两种操作不能混为一谈。
- 规则按程序路径、类、标题精确匹配；不唯一时不猜测；不把收起保存为自动规则。
- JSON 保存设置与恢复记录。PID / 进程启动时间 / 窗口类验证身份，首次危险修改前落盘。正常退出保留用户规则。
- 不自动提权，不结束被管理进程。逐像素透明且不能恢复的目标只拒绝不透明度操作。
- 不预建插件平台、自动布局引擎、工作区编排或数据库。

## 2026-11-10 · 审查修正与界面减法（本节覆盖首版布局）

用户要求修正异常置顶、后台唤醒与退出问题，并删除界面冗余元素、精简层级。

- 删除左侧导航、大标题、副标题、宣传语、版本角标、通用窗口占位图标、计数标题、重复状态与装饰分隔线。
- 主界面改为一条工具栏 + 窗口列表 / 直接操作两栏；列表分类改为横向筛选。取消每行卡片边框和右侧外层卡片。
- 设置只保留顶栏一个入口，内页可直接返回，不嵌套弹窗。PID / HWND / 路径通过“复制窗口信息”按需获取；提示只在实际操作时短暂出现。
- 本体层级只用原生非激活路径，手动、焦点、小窗的意图不混淆。失焦时不仅去除 TOPMOST，还给新前台窗口让位。唤醒临时抬层在 finally 立即撤销或归入当前策略，不依赖空闲回调。
- 目标窗口的同步 Win32 修改移到工作线程。同一窗口只有一个在途修改，其他窗口独立执行；主线程只负责状态、交互与恢复日志。
- 退出最多等待 900ms 的恢复工作，不因失败重新打开主窗或拒绝退出。未完成的恢复日志保留，下次启动继续；不把异步提交当成已恢复。
- 管理员实例明确放行无参数 Show 消息；普通第二次启动即使无法访问管理员互斥体，也尝试该窗口唤醒入口，并检查投递结果。
- 自动测试包括真实主程序实例的托盘隐藏、再次启动唤醒、最小化恢复；用真实阻塞 WndProc 验证 UI、其他目标与退出不被拖住。

真实全屏游戏、跨完整性级别和混合 DPI 仍按 docs/MANUAL_TESTS.md 验收。自动化没有覆盖的场景不得宣称已验证。
